# Poker glossary

Definitions assume standard games unless a variant is named. Thai equivalents preserve English jargon where it aids source lookup.

| Term | Thai | Meaning |
|---|---|---|
| Action | แอ็กชัน | A player’s betting choice. |
| Ante | แอนตี | Forced contribution by all eligible players. |
| Backdoor draw | ดรอว์สองถนน | Draw needing both turn and river. |
| Bankroll | เงินทุนโป๊กเกอร์ | Funds allocated to poker variance. |
| Bet sizing | ขนาดเดิมพัน | Amount chosen for a bet or raise. |
| Big blind | บิ๊กบลายด์ | Larger forced blind; common stack unit. |
| Blocker | ไพ่บัง | Visible card reducing possible opponent combos. |
| Bluff | บลัฟ | Bet seeking folds from better hands. |
| Bluff catcher | มือจับบลัฟ | Hand beating bluffs but little value. |
| Board | บอร์ด | Community cards in flop games. |
| Bring-in | บริ่งอิน | Forced opening wager in some stud games. |
| Bubble | บับเบิล | Stage just before a payout threshold. |
| Call | คอล | Match the amount required to continue. |
| Cash game | เกมเงินสด | Chips usually represent money directly. |
| Check | เช็ก | Pass action without betting when permitted. |
| Check-raise | เช็กเรส | Check then raise after another player bets. |
| Chip EV | มูลค่าชิปคาดหวัง | Expected change in tournament chips. |
| Combo | คอมโบ | Specific card combination making a holding. |
| Continuation bet | ซีเบ็ต | Bet after flop by previous street aggressor. |
| Dead card | ไพ่ตาย | Known unavailable card, often exposed in stud. |
| Dominated | ถูกครอบงำ | Likely to make a weaker version of opponent’s hand. |
| Double-suited | สองดอก | Four-card Omaha hand with two cards of each of two suits. |
| Draw | ดรอว์ | Hand needing future cards to improve. |
| Effective stack | สแตกที่มีผล | Smaller amount two opponents can wager against each other. |
| Equilibrium | สมดุล | Strategy profile resistant to unilateral profitable change. |
| Equity | อิควิตี | Expected share of a pot at showdown. |
| EV | มูลค่าคาดหวัง | Average net result over comparable repetitions. |
| Exploit | ปรับเล่นเพื่อเอาเปรียบ | Deviation targeting a measured opponent tendency. |
| Flop | ฟลอป | First three community cards. |
| Fold equity | โอกาสทำให้หมอบ | Value from opponents folding to aggression. |
| Full ring | โต๊ะเต็ม | Table with more seats than six-max. |
| GTO | เกมเธียรีออพทิมัล | Equilibrium-oriented strategy under a model. |
| Heads-up | สองคน | Hand contested by two players. |
| ICM | โมเดลชิปอิสระ | Model converting tournament stacks to prize equity. |
| Implied odds | ออดส์จากเงินอนาคต | Current call justified partly by possible later wins. |
| Initiative | ความเป็นฝ่ายรุก | Prior aggressive action shaping likely response. |
| In position | มีตำแหน่ง | Acting later than opponent postflop. |
| Kicker | ไพ่คิกเกอร์ | Side card breaking ties within a rank class. |
| Low qualifier | เกณฑ์โลว์ | Condition for a low hand to win a split pot. |
| MDF | ความถี่ป้องกันขั้นต่ำ | Toy-model defense benchmark P/(P+B). |
| Multiway | หลายคน | Pot with at least three active players. |
| Nuts | นัตส์ | Best possible hand on the current board. |
| Out | เอาต์ | Unseen card that would turn a hand into a winner. |
| Out of position | เสียตำแหน่ง | Acting earlier than opponent postflop. |
| Overbet | โอเวอร์เบ็ต | Bet larger than current pot. |
| Polarized | เรนจ์สองขั้ว | Range concentrated in strong value and bluffs. |
| Pot odds | พอตออดส์ | Immediate price of a call relative to pot. |
| Pot limit | พอตลิมิต | Betting structure whose raise cap derives from pot. |
| Preflop | ก่อนฟลอป | Betting before community cards appear. |
| Prize EV | มูลค่ารางวัลคาดหวัง | Expected money payout in a tournament. |
| Push/fold | ชอฟหรือหมอบ | Short-stack choice between all-in and fold. |
| Rake | เรก | Fee taken by cardroom from play. |
| Range | เรนจ์ | Weighted set of possible hands. |
| Redraw | ดรอว์ซ้ำ | Way to improve after making a hand. |
| Reverse implied odds | ออดส์อนาคตเชิงลบ | Possible future loss when an improved hand remains second best. |
| River | ริเวอร์ | Fifth community card and last street. |
| Semi-bluff | เซมิบลัฟ | Bet with fold equity and draw equity. |
| Set | เซ็ต | Three of a kind formed from a pocket pair. |
| Short stack | สแตกสั้น | Stack small relative to blinds or pot. |
| Showdown | เปิดไพ่ | Compare remaining hands after final betting. |
| Side pot | พอตข้าง | Separate pot when players have unequal all-ins. |
| Slowplay | เล่นช้าเพื่อซ่อนมือ | Understate strong hand to induce later action. |
| SPR | สแตกต่อพอต | Effective stack divided by pot at street start. |
| Squeeze | สควีซ | Reraise after a raise and one or more calls. |
| Straddle | สแตรดเดิล | Optional or required predeal live blind under house rules. |
| Street | ถนน | Stage of deal and betting. |
| Tilt | ทิลต์ | Emotional disruption of decision quality. |
| Turn | เทิร์น | Fourth community card. |
| Value bet | แวลูเบ็ต | Bet seeking profitable calls from worse hands. |
| Variance | ความแปรปรวน | Spread of outcomes around expectation. |
| Wrap | แรป | Omaha straight draw with many completing ranks. |
