# PLO Starting Hands — ตัดสินใจ preflop ชุด 1

Source: nuttakitkundum.com PLO Starting Hands (drills adapted from Jeff Hwang, Pot-Limit Omaha Poker: The Big Play Strategy)
URL: https://www.nuttakitkundum.com/plo-starting-hands
Checked: 2026-09-23
Evidence: Preflop decision drill by position and action.

- มือ A♣A♦T♥6♠ (AAT6 rainbow) สถานการณ์: อยู่ button มีผู้เล่น limp มาก่อนหน้าคุณ 3 คน → คำตอบ Call: Call (limp) นี่คือมือ AA แบบ trash คุณยังอยากเห็น flop แต่ไม่อยาก raise ด้วยมือนี้
- มือ A♠A♣T♠5♣ (AAT5 double-suited) สถานการณ์: อยู่ button มีผู้เล่น limp มาก่อนหน้าคุณ 3 คน → คำตอบ Raise: Raise double-suited aces คุ้มที่จะ raise จากตำแหน่งหลัง
- มือ A♦A♣9♦5♣ (AA95 double-suited) สถานการณ์: อยู่ small blind มีผู้เล่น limp 4 คน → คำตอบ Call: Call ลำพัง double-suited aces ยังไม่คู่ควรกับการ raise จากตำแหน่งหน้า และมือนี้ทำ nut straight ไม่ได้ ยิ่งทำให้อ่อนลงไปอีก — อยู่ SB และมีคน limp มาก่อนแล้ว จึงเป็นการ call/complete ไม่ใช่ open-limp
- มือ A♠A♣8♠7♣ (AA87 double-suited) สถานการณ์: UTG (คนแรกที่ต้องลงมือ) → คำตอบ Raise: Raise double-suited aces พร้อม sidecard ที่เชื่อมกันคุ้มที่จะ raise จากทุกตำแหน่ง
- มือ A♣A♥J♣T♦ (AAJT single-suited) สถานการณ์: อยู่ small blind มีผู้เล่น limp 3 คน แล้ว button raise → คำตอบ Call: Call ในเกม stack ลึก คุณไม่รังเกียจที่จะสร้าง value pot แต่เมื่อเจอ raise คุณไม่อยาก reraise — เพราะเสี่ยงจะเล่น heads-up โดยเสียตำแหน่ง ซึ่งเป็นสูตรหายนะ
- มือ A♠A♦T♠T♦ (AATT double-suited) สถานการณ์: อยู่ button มี raise และ call สองคน มาก่อนหน้าคุณ → คำตอบ Reraise: Reraise pair ที่สองและการเป็น double-suited ทำให้มือนี้เปอร์เซ็นต์สูงพอที่จะ reraise ได้ — และการติด set จาก pair อีกคู่ยังเพิ่มการอำพราง
- มือ A♠A♦J♠3♣ (AAJ3 single-suited) สถานการณ์: UTG คุณ limp; คนถัดไป raise เป็น $25; มี call 3 คน; ทั้งสอง blind call → คำตอบ Call: แค่ Call คุณจะ raise เป็น ~$200 ก็ได้ แต่ด้วย stack $1,000 คุณจะให้ราคาคนอื่นมา outdraw aces ของคุณ คุณจะได้คน call ไม่ใช่ pot — ปล่อยให้เล่นหลายทางและถูกๆ ไว้
