### จุดอ่อนเชิงโครงสร้างที่ลดเกรดมือ
- ถูกdominateเพราะไพ่ต่ำ straight เล็กมักโดน straight ใหญ่กว่ากดทับ 9-7-5-3 เป็น Trash เพราะ straight ที่ติดล้วนถูกdominate
- non-nut draw การไล่ second-nut flush หรือ sucker straight (ที่ติดปลายบนแล้วได้ straight อันดับสอง) มีแต่เสียเงิน
- dangler (ไพ่หลุด) ไพ่เดี่ยวที่ไม่เชื่อมกับใคร (เลข 4 ใน A-K-Q-4) ทำให้กลายเป็นมือสามใบโดยปริยาย
- top gap (ช่องว่างด้านบน) K-J-T-9 เสียเปรียบเชิงโครงสร้าง — ช่องว่างอยู่ด้านบน จึงทำ nut wrap แบบ rundown แท้ๆ ไม่ได้
- pair ต่ำที่ทำ top set ไม่ได้ pair 6 ติด top set ไม่ได้เลยถ้าบน board ยังไม่มีโอกาสเกิด straight
"Hold'em สองมือรวมกันไม่เป็นมือ Omaha" Q-J + 7-6 ดูเล่นได้แต่สองส่วนไม่เชื่อมกัน จึงแทบไม่มีศักยภาพทำเงินก้อนใหญ่ ความเชื่อมโยงสำคัญกว่าแต้มไพ่
### อะไรทำให้ Premium เป็น Premium
- suited ace draw ไปหา nut flush ไม่ใช่ flush อันดับสอง
- double-suited aces พร้อม connectors (เช่น A-A-8-7 ds) เพิ่มศักยภาพเล่นหลายทางบนพื้นฐานของ top set
- big double pair อย่าง Q-Q-J-J ติด set 21.4% ของครั้ง — โอกาสติดสูงทำให้เป็น Premium แม้ผลที่ได้มักเป็นมือทางเดียว
- premium rundown (เช่น J-T-9-8 ds) ทำ nut straight draw, two pair พร้อม open-ender และมีโอกาส freeroll สูง — "มือ PLO ของจริง"
- Magnum — A-A-J-T ds — คือสุดยอดมือ: straight draw ที่dominate, nut flush draw สองดอก และโอกาส top set ครบในมือเดียว
เล่นเพื่อ nut ใน Omaha มืออันดับสองและ second-nut draw คือสาเหตุที่ทำให้เสีย stack เมื่อไม่แน่ใจ ให้ถามว่ามือนี้ทำ nut ได้ไหม ไม่ใช่แค่ทำมืออะไรสักอย่าง
