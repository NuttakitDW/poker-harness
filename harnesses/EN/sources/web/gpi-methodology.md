# Global Poker Index ranking method

Source: Global Poker Index official about page, retrieved through a web search index because direct page access failed
URL: https://www.globalpokerindex.com/about/
Checked: 2026-09-22
Evidence: GPI publishes a weekly live tournament ranking based on qualifying cash finishes in the preceding 36 months. Finish position relative to field, buy-in, and recency affect scores; only a capped set of results counts. It measures a different thing from a lifetime gross-cashes list.
