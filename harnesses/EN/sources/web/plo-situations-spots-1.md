# PLO Post-Flop Situations — สถานการณ์หลัง flop ชุด 1

Source: nuttakitkundum.com PLO Post-Flop Situations (drills adapted from Jeff Hwang, Pot-Limit Omaha Poker: The Big Play Strategy)

Evidence: Post-flop decision drill from Hwang Chapter 6.

- มือ J♠T♦9♠7♦ (JT97 double-suited) board J♦8♠6♥8♦ (J868 single-suited) สถานการณ์: $5/$5/$10 UTG คุณ raise เป็น $30 และมีคน call flop ให้ top pair + 17-card straight draw คุณ bet $150 มี blind คนหนึ่ง call turn ทำให้ board เป็น pair (8♦) ให้ flush draw และ two pair — แล้วคู่ต่อสู้ bet $300 (คุณ cover, เหลือ ~$400) → คำตอบ Fold: Fold turn ทำให้ board เป็น pair และคู่ต่อสู้จู่ๆ ก็ยิงก้อนใหญ่ — ให้เครดิตว่ามี trip 8 หรือ straight ที่ติดแล้ว two pair บวก non-nut flush draw ตรงนี้เหลือ out น้อยหรือ drawing dead
- มือ 7♠6♦5♠2♥ (7652 single-suited) board A♠4♦3♠ สถานการณ์: $1/$2 เล่นหลายทาง pot ที่ไม่มีการ raise flop ให้ nut wrap พร้อม flush draw (7-6-5-2 บน A-4-3) big blind check มาหาคุณ → คำตอบ Bet the pot: Bet the pot nut wrap พร้อม flush draw คือ draw ยักษ์ที่มักเป็นต่อเมื่อเล่นหลายทาง อย่า slow-play — สร้าง pot และเอาเงินเข้าตอนนี้
- มือ 9♠9♥5♠3♦ (9953 single-suited) board 9♦8♠4♥7♣ (9847 rainbow) สถานการณ์: $2/$4 คุณ flop top set (9-8-4) จาก small blind, check-raise flop แล้วมีคน call turn เป็น 7♣ ทำให้เกิด straight บน board ถึงตาคุณ → คำตอบ Check แล้ว fold เมื่อเจอ bet เต็ม pot: Check แล้ว fold เมื่อเจอ bet เต็ม pot 7 เติม straight ชัดๆ และคน call flop น่าจะมี straight draw หรือ J-T อยู่แล้ว top set ไม่คุ้มจะทุ่มหมดใส่ straight ที่ติดแล้ว
- มือ Q♥Q♦5♦5♣ (QQ55 single-suited) board K♦7♣5♥ สถานการณ์: $0.50/$1 คุณ flop bottom set (5) บน K-7-5 คุณ bet $7 แล้วโดน raise เป็น $28 → คำตอบ Fold: Fold bottom set ที่โดน raise มักตามหลัง set ที่ใหญ่กว่าหรือ two pair + draw และต่อให้ดีที่สุดก็ไม่ได้นำ straight draw มากนัก ปล่อยไป
