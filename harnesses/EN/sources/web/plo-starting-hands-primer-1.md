### หลักการ
ทุกมือเริ่มต้นใน Omaha แบ่งได้เป็น 4 ระดับ: Premium, Speculative, Marginal, หรือ Trash วิธีทดสอบของ Hwang นั้นง่ายมาก — ลองนึกถึง flop ที่ดีที่สุดเท่าที่มือนี้จะติดได้ ("miracle flop") แล้วถามว่าผลลัพธ์นั้นดีจริงแค่ไหน และ flop แบบนั้นมาบ่อยแค่ไหน
เพราะ Omaha บังคับให้ใช้ ไพ่ในมือ 2 ใบจาก 4 ใบพอดี คุณค่าของมือจึงอยู่ที่ โครงสร้าง — ว่าไพ่ประกอบกันเป็น nut straight, nut flush draw, big wrap และ top set ได้ดีแค่ไหน ไพ่สวยที่ไม่เชื่อมกันแทบไม่มีค่า
### สี่ระดับของมือ
- Premium — ไพ่สูงที่เชื่อมกัน, double-suited aces, big double pair, premium rundown ติด nut straight, nut flush draw, top set หรือ big wrap ได้ — คุ้มที่จะ raise หลายมือเล่นได้จากทุกตำแหน่ง
- Speculative — มีศักยภาพทำเงินก้อนใหญ่ แต่มีจุดอ่อนเชิงโครงสร้าง — ไพ่ต่ำ, non-nut draw หรือมีช่องว่าง หลายมือก็ยัง flop monster hand ได้ — เป็นมือไว้ call; raise มือใหญ่ๆ ในตำแหน่งหลัง
- Marginal — มือทางเดียว: pair เดี่ยว, มือสามใบ, หรือมือที่ช่องว่างอยู่ด้านบน ทำได้อย่างเดียวแทบไม่มีอย่างอื่น — เล่นตำแหน่งหลัง ลง bet ขั้นต่ำเท่านั้น — อาศัยความได้เปรียบจากตำแหน่ง
- Trash — draw ที่ถูกdominate, second-nut draw, มือ "Hold'em สองมือ" ที่ไม่เชื่อมกัน, หรือ pair ต่ำที่ทำ top set ไม่ได้โดยไม่มี straight บน board — fold (หรือนานๆ ครั้ง limp เฉพาะมือที่ดีที่สุดเมื่ออยู่ในตำแหน่ง)
