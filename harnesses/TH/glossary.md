# ศัพท์โป๊กเกอร์

คำแปลคงศัพท์อังกฤษที่ช่วยค้นต้นฉบับ และระบุเกมย่อยเมื่อความหมายต่างกัน

| English | ไทย | ความหมาย |
|---|---|---|
| Action | แอ็กชัน | ทางเลือกเดิมพันของผู้เล่น |
| Ante | แอนตี | เงินบังคับที่ผู้เล่นที่เข้าเกณฑ์ต้องลง |
| Backdoor draw | ดรอว์สองถนน | ดรอว์ที่ต้องได้ไพ่ช่วยทั้ง turn และ river |
| Bankroll | เงินทุนโป๊กเกอร์ | เงินที่จัดไว้รองรับความผันผวนของโป๊กเกอร์ |
| Bet sizing | ขนาดเดิมพัน | จำนวนเงินที่เลือก bet หรือ raise |
| Big blind | บิ๊กบลายด์ | blind บังคับที่ใหญ่กว่าและเป็นหน่วยวัดสแตก |
| Blocker | ไพ่บัง | ไพ่ที่เห็นซึ่งลดคอมโบที่คู่ต่อสู้อาจมี |
| Bluff | บลัฟ | เดิมพันเพื่อให้มือที่ดีกว่าหมอบ |
| Bluff catcher | มือจับบลัฟ | มือที่ชนะ bluff แต่แพ้มือ value ส่วนใหญ่ |
| Board | บอร์ด | ไพ่กลางในเกมประเภท flop |
| Bring-in | บริ่งอิน | เงินเปิดบังคับใน stud บางชนิด |
| Bubble | บับเบิล | ช่วงก่อนเข้าสู่อันดับได้เงินรางวัล |
| Call | คอล | จ่ายเงินตามจำนวนที่ต้องใช้เพื่อเล่นต่อ |
| Cash game | เกมเงินสด | เกมที่ชิปมักแทนเงินจริงโดยตรง |
| Check | เช็ก | ส่งต่อคิวโดยไม่ bet เมื่อกติกาอนุญาต |
| Check-raise | เช็กเรส | check ก่อนแล้ว raise เมื่ออีกคน bet |
| Chip EV | มูลค่าชิปคาดหวัง | การเปลี่ยนชิปทัวร์นาเมนต์ที่คาดหวัง |
| Combo | คอมโบ | ชุดไพ่จริงชุดหนึ่งที่ประกอบเป็นมือ |
| Continuation bet | ซีเบ็ต | bet หลัง flop ของผู้รุกก่อนหน้า |
| Dead card | ไพ่ตาย | ไพ่ที่ทราบว่าใช้ไม่ได้ มักเป็นไพ่หงายใน stud |
| Dominated | ถูกครอบงำ | มีแนวโน้มทำมือประเภทเดียวกันแต่ด้อยกว่า |
| Double-suited | สองดอก | มือ Omaha สี่ใบที่มีดอกละสองใบในสองดอก |
| Draw | ดรอว์ | มือที่ต้องอาศัยไพ่ถัดไปให้แข็งแรงขึ้น |
| Effective stack | สแตกที่มีผล | เงินสูงสุดที่คู่เล่นสองคนเดิมพันกันได้ตามสแตกที่สั้นกว่า |
| Equilibrium | สมดุล | ชุดกลยุทธ์ที่ฝ่ายเดียวเปลี่ยนแล้วไม่เพิ่มกำไร |
| Equity | อิควิตี | ส่วนพอตที่คาดว่าจะได้เมื่อเปิดไพ่ |
| EV | มูลค่าคาดหวัง | ผลสุทธิเฉลี่ยหากเกิดสถานการณ์คล้ายกันซ้ำ |
| Exploit | ปรับเล่นเพื่อเอาเปรียบ | การปรับกลยุทธ์ตามจุดอ่อนที่สังเกตได้ |
| Flop | ฟลอป | ไพ่กลางสามใบแรก |
| Fold equity | โอกาสทำให้หมอบ | มูลค่าจากโอกาสที่คู่ต่อสู้หมอบ |
| Full ring | โต๊ะเต็ม | โต๊ะที่มีที่นั่งมากกว่าแบบหกคน |
| GTO | เกมเธียรีออพทิมัล | กลยุทธ์อิงสมดุลภายใต้แบบจำลอง |
| Heads-up | สองคน | มือที่เหลือผู้เล่นสองคน |
| ICM | โมเดลชิปอิสระ | โมเดลแปลงสแตกทัวร์นาเมนต์เป็นมูลค่ารางวัล |
| Implied odds | ออดส์จากเงินอนาคต | ผลตอบแทนจากเงินที่อาจชนะเพิ่มในถนนถัดไป |
| Initiative | ความเป็นฝ่ายรุก | บทบาทผู้รุกจากแอ็กชันก่อนหน้า |
| In position | มีตำแหน่ง | ตัดสินใจทีหลังคู่ต่อสู้หลัง flop |
| Kicker | ไพ่คิกเกอร์ | ไพ่รองที่ใช้ตัดสินเมื่อชนิดมือเท่ากัน |
| Low qualifier | เกณฑ์โลว์ | เงื่อนไขที่มือ low ต้องผ่านจึงได้ส่วนพอต |
| MDF | ความถี่ป้องกันขั้นต่ำ | เกณฑ์โมเดลอย่างง่าย P/(P+B) ที่ขึ้นกับสมมติฐาน |
| Multiway | หลายคน | พอตที่มีผู้เล่นอย่างน้อยสามคน |
| Nuts | นัตส์ | มือที่ดีที่สุดที่เป็นไปได้บนบอร์ดปัจจุบัน |
| Out | เอาต์ | ไพ่ที่ยังไม่เห็นซึ่งทำให้มือเปลี่ยนเป็นชนะ |
| Out of position | เสียตำแหน่ง | ตัดสินใจก่อนคู่ต่อสู้หลัง flop |
| Overbet | โอเวอร์เบ็ต | bet มากกว่าขนาดพอตปัจจุบัน |
| Polarized | เรนจ์สองขั้ว | เรนจ์ที่เน้นมือใหญ่และ bluff |
| Pot odds | พอตออดส์ | ราคาของ call เทียบกับพอตที่ชิงได้ |
| Pot limit | พอตลิมิต | โครงสร้างที่เพดาน raise คำนวณจากพอต |
| Preflop | ก่อนฟลอป | รอบเดิมพันก่อนไพ่กลางเปิด |
| Prize EV | มูลค่ารางวัลคาดหวัง | เงินรางวัลที่คาดว่าจะได้ในทัวร์นาเมนต์ |
| Push/fold | ชอฟหรือหมอบ | ทางเลือกสแตกสั้นระหว่าง all-in กับ fold |
| Rake | เรก | ค่าธรรมเนียมที่ห้องเกมเก็บ |
| Range | เรนจ์ | ชุดมือที่เป็นไปได้พร้อมน้ำหนักความถี่ |
| Redraw | ดรอว์ซ้ำ | โอกาสพัฒนามือให้ใหญ่ขึ้นหลังติดมือแล้ว |
| Reverse implied odds | ออดส์อนาคตเชิงลบ | เงินอนาคตที่อาจเสียเมื่อมือดีขึ้นแต่ยังแพ้ |
| River | ริเวอร์ | ไพ่กลางใบที่ห้าและถนนสุดท้าย |
| Semi-bluff | เซมิบลัฟ | bet ที่มีทั้งโอกาสทำให้หมอบและโอกาสดรอว์ติด |
| Set | เซ็ต | ตองที่เกิดจากคู่ในมือส่วนตัว |
| Short stack | สแตกสั้น | สแตกน้อยเมื่อเทียบ blind หรือพอต |
| Showdown | เปิดไพ่ | เทียบมือของผู้เล่นที่เหลือเมื่อเดิมพันจบ |
| Side pot | พอตข้าง | พอตแยกเมื่อผู้เล่น all-in ด้วยเงินไม่เท่ากัน |
| Slowplay | เล่นช้าเพื่อซ่อนมือ | ลดการรุกด้วยมือใหญ่เพื่อให้คู่ต่อสู้เล่นต่อ |
| SPR | สแตกต่อพอต | effective stack หารพอต ณ ต้นถนน |
| Squeeze | สควีซ | raise ซ้ำหลังมีคน raise และอย่างน้อยหนึ่ง call |
| Straddle | สแตรดเดิล | blind เพิ่มก่อนแจกตามกติกาห้อง |
| Street | ถนน | ช่วงการแจกไพ่และเดิมพัน |
| Tilt | ทิลต์ | อารมณ์ที่รบกวนคุณภาพการตัดสินใจ |
| Turn | เทิร์น | ไพ่กลางใบที่สี่ |
| Value bet | แวลูเบ็ต | bet เพื่อรับ call ที่คุ้มจากมือแย่กว่า |
| Variance | ความแปรปรวน | การกระจายของผลจริงรอบค่าคาดหวัง |
| Wrap | แรป | สเตรทดรอว์ Omaha ที่มีไพ่ช่วยหลายอันดับ |
