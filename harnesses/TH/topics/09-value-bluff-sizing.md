# เดิมพันเพื่อมูลค่า การบลัฟ และขนาดเดิมพัน

- รหัสคงที่: `09-value-bluff-sizing`
- ขอบเขต: สูตรบลัฟ river แบบสองคนที่เรียบง่าย; มือจริงมี call, raise, rake และ blocker
- ฉบับอังกฤษ: [Value betting, bluffing and sizing](../../EN/topics/09-value-bluff-sizing.md)

## แนวคิดหลัก

value bet คือ bet ที่คาดว่าจะได้ call จากมือแย่กว่ามากพอจนดีกว่า check pure bluff ไม่มีมูลค่าเมื่อเปิดไพ่และต้องการให้คู่ต่อสู้หมอบ หากเสี่ยง B เพื่อเก็บพอต P ความถี่หมอบคุ้มทุนคือ B/(P+B) ภายใต้เงื่อนไขว่าหมอบแล้วได้ P และถูก call แล้วเสีย B ขนาด bet เปลี่ยนเรนจ์ที่คู่ต่อสู้จะ call จึงเปลี่ยนทั้งมือ value และ bluff บลัฟครึ่งพอตต้องทำให้หมอบมากกว่า 1/3 ก่อน rake มืออ่อนที่ยังมี showdown value อาจ check ดีกว่า

## มือใดควร bet

- เริ่มจาก **เรนจ์ที่คู่ต่อสู้จะเล่นต่อ** ไม่ใช่มือที่เราอยากให้เขาถือ เขียนมือแย่กว่าที่ call และมือดีกว่าที่ fold
- สำหรับ value ให้เทียบ bet กับ check โดยรวมโอกาสถูก raise value บาง ๆ ดีต่อคน call กว้าง แต่อาจไม่ดีต่อคนที่หมอบมือแย่เกือบหมด
- pure bluff ใช้ B/(P+B) เฉพาะเมื่อไม่มี showdown equity และถูก call แล้วเสีย B พอดี หากเป็นดรอว์ต้องรวม equity เมื่อถูก call หากเป็นคู่เล็กต้องเทียบ EV ของ check
- บน river เลือก bluff ที่บังมือสำคัญของคู่ต่อสู้และมี showdown value ต่ำ จากนั้นตรวจว่าคู่ต่อสู้มีคอมโบที่หมอบได้พอหรือไม่

## ตัวอย่างที่เรียบเรียงใหม่ (ไม่ได้คัดจากต้นฉบับ)

ตัวอย่างที่เรียบเรียงใหม่: บลัฟ $75 ลงพอต $100 ต้องให้หมอบ 75/175 ≈ 42.9%; ถ้าหมอบ 50% จะได้ EV = .5×100 − .5×75 = +$12.50

## ฝึกใช้และตรวจขอบเขต

ขนาด bet มีการแลกเปลี่ยน bet value ใหญ่ได้เงินต่อ call มากแต่คนอาจ call น้อยลง bet เล็กอาจได้ call จากมือก้ำกึ่งกว้างกว่า ขนาดที่ดีที่สุดจึงขึ้นกับความถี่ตอบสนอง ไม่ใช่ความแข็งของมืออย่างเดียว bluff ใหญ่เสี่ยงเสีย B เต็มเมื่อถูกจับ แม้อาจทำให้มือแข็งหมอบมากขึ้น แต่ pure bluff ต้องการความถี่หมอบสูงขึ้น เมื่อคาดการตอบสนองต้องตัดมือที่ blocker ทำให้เป็นไปไม่ได้และรวมโอกาสถูก raise ในพอตหลายคนมีโอกาสที่อย่างน้อยหนึ่งคนเล่นต่อสูงขึ้น สูตรสองคนอย่างง่ายจึงไม่พอ

## ข้อผิดพลาดที่พบบ่อย

สับสนความถี่หมอบคุ้มทุนของ bluff กับ equity ที่ต้องใช้ call; bet เพื่อ value เฉพาะ nuts
