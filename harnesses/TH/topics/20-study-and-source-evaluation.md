# การศึกษา Workbook และการประเมินแหล่งข้อมูล

- รหัสคงที่: `20-study-and-source-evaluation`
- ขอบเขต: เอกสารต่างยุคและต่างเกม; ตัวอย่างต้องอ่านพร้อมสมมติฐานต้นฉบับ
- ฉบับอังกฤษ: [Study, workbooks and source evaluation](../../EN/topics/20-study-and-source-evaluation.md)

## แนวคิดหลัก

ฝึกมือหนึ่งโดยเขียนตำแหน่ง effective stack พอต บอร์ด แอ็กชัน และเรนจ์ที่เป็นไปได้ก่อนดูเฉลย คำนวณคอมโบ pot odds และ EV ด้วยตนเอง แล้วเทียบกับ workbook พร้อมอธิบายจุดที่ต่าง จัดกลุ่มความผิดพลาดตามแนวคิด กลับมาทบทวนภายหลัง และลองกับมือใหม่ ข้อความ Markdown เป็นการถอดตามหน้าจริง จึงอาจขาดภาพ ตาราง หรือสมการ เมื่อรูปแบบหน้าสำคัญให้เปิด PDF หน้าที่อ้างอิง คำแนะนำเชิงยุทธวิธีในหนังสือเก่าควรอ่านตามสภาพเกมของยุคนั้น ไม่ใช่ชาร์ตตลอดกาล

## แบบฝึกที่ทำซ้ำได้

เลือกโจทย์ workbook หนึ่งข้อและปิดเฉลย เขียนไพ่ที่ทราบ พอตก่อนแอ็กชัน เงินที่ต้อง call effective stack และคำถามให้ครบ คำนวณเอง: โจทย์คอมโบต้องตัด blocker; โจทย์ pot odds ต้องแยก equity สำหรับ call จากความถี่หมอบสำหรับ bluff จดทั้งคำตอบตัวเลขและสมมติฐาน แล้วค่อยเทียบเฉลยและหาสาเหตุที่ต่าง หาก OCR แสดงไพ่แปลกหรือดอกหาย ให้เปิดหน้า PDF เพราะตัวอักษรที่ถอดอาจผิด

หลังฝึกให้หามือใหม่ที่ใช้แนวคิดเดียวกัน แล้วอธิบายแอ็กชันหนึ่งประโยคแก่ผู้เริ่มต้น การจำเฉลยหนึ่งข้อมีค่าน้อยกว่าวิธีที่ใช้ได้เมื่อขนาดพอต ตำแหน่ง และคู่ต่อสู้เปลี่ยน

## ตัวอย่างที่เรียบเรียงใหม่ (ไม่ได้คัดจากต้นฉบับ)

ตัวอย่างที่เรียบเรียงใหม่: คำนวณ AK offsuit 12 และ suited 4 คอมโบก่อนเปิดเฉลย workbook แล้วลองใหม่เมื่อเห็น A หนึ่งใบว่าจำนวนเปลี่ยนอย่างไร

## ฝึกใช้และตรวจขอบเขต

การอ้างแหล่งข้อมูลควรละเอียดให้ agent อื่นตรวจได้: ชื่อเล่ม หน้า PDF จริง และสมมติฐานที่นำมาใช้ Markdown ที่ถอดตามหน้ารักษาลำดับหน้าแต่ไม่รับประกันว่าสมการ ภาพ หรือดอกครบ ข้ออ้างตัวเลขต้องคำนวณตรวจเองและเปิดภาพ PDF เมื่อสัญลักษณ์เสีย แยกตัวอย่างจากหนังสือกับตัวอย่างที่เราแต่งใหม่ หากสองเล่มขัดกัน ให้เทียบชนิดเกม ยุคตีพิมพ์ rake ความลึกสแตก และแบบจำลองคู่ต่อสู้ก่อนเลือกว่าแนวคิดใดใช้ได้

## ข้อผิดพลาดที่พบบ่อย

อ่านเฉลยโดยไม่ตั้งสถานการณ์เอง; เชื่อข้อความ OCR เมื่อมีภาพหรือเครื่องหมายคณิตศาสตร์ที่อาจหาย
