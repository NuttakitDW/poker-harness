# PLO มือเริ่มต้นและการตัดสินใจ preflop

- Stable ID: `25-plo-starting-hands`
- Scope: จัดระดับมือเริ่มต้น Pot-Limit Omaha สี่ใบ และเลือก fold, limp, call, raise ก่อน flop ตามกรอบ Big Play ของ Jeff Hwang
- English counterpart: [PLO starting hands and preflop decisions](../../EN/topics/25-plo-starting-hands.md)

## แนวคิดหลัก

มือเริ่มต้น PLO แบ่งสี่ระดับ Premium, Speculative, Marginal, Trash วิธีทดสอบคือนึกถึง miracle flop ที่ดีที่สุดของมือ แล้วถามว่าผลนั้นเป็น nuts จริงไหม และ flop ใกล้เคียงมาบ่อยแค่ไหน เพราะต้องใช้ไพ่ในมือสองใบพอดี ค่าของมือจึงอยู่ที่โครงสร้าง คือไพ่ทั้งสี่ใบช่วยกันทำ nut straight, nut flush draw, big wrap และ top set ได้แค่ไหน ไพ่สวยที่ไม่เชื่อมกันแทบไม่มีค่า

Premium คือไพ่สูงที่เชื่อมกัน double-suited aces big double pair อย่าง QQJJ และ premium rundown อย่าง JT98 double-suited raise ได้และหลายมือเล่นได้ทุกตำแหน่ง มือที่ดีที่สุดคือ AAJT double-suited (Magnum) Speculative มีศักยภาพก้อนใหญ่แต่มีจุดอ่อน เช่น ไพ่ต่ำ non-nut draw หรือมีช่องว่าง เป็นมือไว้ call และ raise มือใหญ่ในตำแหน่งหลัง Marginal เป็นมือทางเดียว เช่น pair เดี่ยว มือสามใบ หรือ top gap อย่าง KJT9 เล่นตำแหน่งหลังด้วยเงินขั้นต่ำเท่านั้น Trash คือ draw ที่ถูก dominate second-nut draw มือ Hold'em สองมือที่ไม่เชื่อมกันอย่าง QJ76 หรือ pair ต่ำที่ทำ top set ไม่ได้ ให้ fold

จุดที่ลดเกรดมือ: straight ต่ำถูก straight สูงกว่ากดทับ เช่น 9753 เป็น Trash; flush ที่ไม่ใช่ nut; dangler หรือไพ่หลุดหนึ่งใบที่ไม่เชื่อมกับใคร ทำให้เหลือมือสามใบ; top gap ทำ nut wrap ไม่ได้ Aces ไม่ได้ดีเท่ากันหมด AA double-suited พร้อม connectors raise ได้ทุกตำแหน่ง แต่ AA82 rainbow เป็นแค่ Speculative ที่ต้องติด ace บน flop และเมื่อเจอ raise กับ reraise อย่า call สองเด้งเพียงเพราะถือ aces

ก่อน flop: มีคน limp แล้วเราอยู่ button ให้ raise มือ Premium ที่ double-suited แต่ limp ตามด้วย AA ที่ไม่มีโครงสร้าง จาก small blind เจอ raise ในเกม stack ลึก มักแค่ call เพราะ reraise แล้วต้องเล่น heads-up โดยเสียตำแหน่ง ตัวอย่างและเหตุผลแต่ละมืออยู่ในโน้ตแบบฝึกหัดด้านล่าง

## ตัวอย่างที่เรียบเรียงใหม่ (ไม่ได้คัดจากต้นฉบับ)

ตัวอย่างที่เรียบเรียงใหม่: “KKQJ double-suited เป็น Premium ค่ะ flop T98 ได้ nut straight พร้อม redraw คู่ใหญ่สองคู่และสองดอกทำงานด้วยกันทุกใบ ส่วน QJ76 ดูเล่นได้แต่เป็น Hold'em สองมือที่ไม่เชื่อมกัน เลยเป็น Trash”
